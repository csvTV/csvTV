iPhone share test

Use Safari on a physical iPhone. This page opens csvTV’s Export screen with two fictional shows.

  1. Choose the four record files and tap Share once. Choose Save to Files and save all four into a new folder. Use the first file picker below to check what arrived.
  2. Tap Share again and dismiss the sheet. Check that Export is still available and the app reports no delivery.
  3. Try a share target that cannot receive the files. Record whether Safari omits the target, the target refuses, or there is no such target to try.
  4. Download each of the four files with its own tap. Use a separate empty folder so iOS can keep the original names. Check the downloaded copies with the second picker.
