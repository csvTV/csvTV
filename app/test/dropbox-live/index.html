Dropbox development test

Use the public key of a dedicated Dropbox App Folder app. Enable files.metadata.read, files.content.read and files.content.write, allow public clients and register http://localhost:8765/ as its redirect address.

The file test creates a folder named csvtv-probe followed by a random ID, checks a fictional file and removes the folder. Keep this tab open for two minutes for the expiry test.

The revocation-only test requests a seven-day refresh token and checks it immediately before and after sign-out.
